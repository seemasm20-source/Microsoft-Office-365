# 📧 Office 365 Troubleshooting Portfolio

---

## 👩‍💻 About This Portfolio

This portfolio documents hands-on troubleshooting
of Microsoft 365 services covering the most common
Tier 1 Help Desk tasks in real corporate environments.

All scenarios are based on real issues encountered
in IT Help Desk roles using Microsoft 365 Admin Center,
Outlook, Exchange Online and Microsoft Teams.

## 📋 Skills Demonstrated

### Microsoft 365 Admin Center
- Create and manage user accounts
- Assign and remove Microsoft 365 licences
- Reset passwords and block sign-in
- Delete and restore user accounts

### Outlook and Exchange Online
- Troubleshoot Outlook sign-in and profile problems
- Fix cannot send and receive email issues
- Resolve sync issues and mail not updating
- Repair corrupted Outlook profiles using ScanPST

### Microsoft Teams
- Diagnose sign-in problems and licence issues
- Troubleshoot microphone, camera and meeting issues
- Run, repair and reset the Teams application
- Clear Teams cache to fix performance issues
