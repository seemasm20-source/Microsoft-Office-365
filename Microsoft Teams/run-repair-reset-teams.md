# Microsoft Teams Repair, Reset and Reinstall



## Objective

Troubleshoot Microsoft Teams desktop app issues such as crashes, freezing, failure to open or persistent problems after basic troubleshooting.

## 1. Fix - Repair Microsoft Teams

1. Open **Windows Settings → Apps → Installed apps**.
2. Search for **Microsoft Teams**.
3. Click the three-dot menu next to Teams → **Advanced options**, if available.
4. Click **Repair** and wait for the process to finish.
5. Reopen Teams and test the affected function.

**Note:** Repair attempts to fix app problems without intentionally clearing the app's local data.

## 2. Fix - Reset Microsoft Teams

Use Reset if Repair does not resolve the issue.

1. Open **Settings → Apps → Installed apps**.
2. Search for **Microsoft Teams** → click the three-dot menu → **Advanced options**, if available.
3. Click **Reset** and confirm.
4. Reopen Teams and sign in again.
5. Test whether the original issue is resolved.

**Caution:** Reset clears local app data and may remove saved preferences or sign-in state. Ensure the user knows they may need to sign in again.

## 3. Fix - Reinstall Microsoft Teams

Use Reinstall if Repair and Reset fail.

1. Open **Settings → Apps → Installed apps**.
2. Find Microsoft Teams → click the three-dot menu → **Uninstall**.
3. Follow the prompts to complete the uninstall.
4. Download Teams from the official Microsoft website:  
   https://www.microsoft.com/en-us/microsoft-teams/download-app
5. Install Teams and sign in with the user's work or school account.
6. Test the feature that was failing.

**Important:** On managed company devices, follow the organisation's software installation policy. Some Teams installations may be managed or deployed by IT.

## 4. Verification

- [ ] Teams opens without crashing or freezing.
- [ ] User can sign in successfully.
- [ ] Chats and teams load correctly.
- [ ] The original issue no longer occurs.
- [ ] The result is documented in the support ticket.
