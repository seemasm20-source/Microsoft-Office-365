
Create and Manage Users


Steps — Create New User
1
Go to admin.microsoft.com → sign in with admin credentials
2
Users → Active Users → Add a user
3
Fill in: First name, Last name, Display name, Username
4
Auto-generate password OR set a temporary password
5
Tick: Require this user to change their password when they first sign in
6
Assign product licences → Microsoft 365 Business → Next
7
Optional settings: Job title, Department, Office, Manager
8
Finish adding → user created ✅
