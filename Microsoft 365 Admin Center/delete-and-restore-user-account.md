# Microsoft 365 - Delete and Restore a User Account


## Objective

Learn how to delete a user account and restore it using the Microsoft 365 Admin Center.

## Prerequisites

* Access to the [Microsoft 365 Admin Center](https://admin.microsoft.com).
* Appropriate administrator permissions.
* The user account you want to delete or restore.

## Steps - Delete a User

1. Sign in to [admin.microsoft.com](https://admin.microsoft.com).
2. Navigate to **Users → Active users**.
3. Select the checkbox next to the user account.
4. Click **Delete user**.
5. Review the confirmation details and confirm the deletion.

**Expected result:** The user account is moved to **Deleted users** and can generally be restored within 30 days.

## Steps — Restore a User

1. Navigate to **Users → Deleted users**.
2. Select the user account you want to restore.
3. Click **Restore user**.
4. Follow the prompts to complete the restoration.
5. Assign a Microsoft 365 licence if required and available.
6. Verify the user's account and service access.

**Expected result:** The account is restored to Active users, subject to the restoration process completing successfully.

## Verification

* Confirm that the restored user appears under **Active users**.
* Verify the username and account details.
* Check the licence assignment and required service access.
