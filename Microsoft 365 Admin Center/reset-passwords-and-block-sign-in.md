# Microsoft 365 - Reset Password and Block Sign-In

## Objective

Learn how to reset a user's password and block sign-in through the Microsoft 365 Admin Center.

## Prerequisites

* Access to the [Microsoft 365 Admin Center](https://admin.microsoft.com).
* Appropriate administrator permissions.
* The correct user account identified and verified.

## Steps - Reset a Password

1. Sign in to [admin.microsoft.com](https://admin.microsoft.com).
2. Navigate to **Users → Active users**.
3. Select the user account.
4. Click **Reset password** in the top menu.
5. Choose to auto-generate a password or enter a temporary password, depending on the available options.
6. Enable **Require this user to change their password when they first sign in**, if available and appropriate.
7. Click **Reset password** to complete the process.
8. Communicate the temporary password to the user securely.

**Expected result:** The password is reset, and the user can sign in using the new temporary password and complete any required password change.

## Steps - Block Sign-In

1. Navigate to **Users → Active users**.
2. Select the user account.
3. Choose **Block sign-in**.
4. Enable **Block this user from signing in**.
5. Click **Save changes**.

**Expected result:** The account is blocked from starting new sign-in sessions after the change takes effect. Existing sessions may need to be revoked separately.

## Verification

* For password reset, confirm the reset operation succeeds and the user can sign in with the new credentials.
* For blocked sign-in, reopen the user's settings and verify that sign-in is blocked.
* If immediate access termination is required, check whether existing sessions need to be revoked.
